# London Girls' Trip 2026 – Reise-App

Eigenständige Reise-App (eine einzige Datei: `london/index.html`) für den
Girls' Trip nach London, 25.–28.09.2026.

**Dieser Branch ist vollständig von der Volleyball-App getrennt**: eigene
Historie, keine gemeinsamen Dateien, wird nicht in die Volleyball-App gemergt.

**Öffnen auf dem Handy:**
https://raw.githack.com/ritvamarx/Volleyballverealtubg/claude/travel-app-group-costs-6d5280/london/index.html
→ in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Funktionen: Reiseplan (bearbeitbar), Euro ⇄ Pfund, Stadtplan mit
Standortfreigabe, ÖPNV-Links, Kostenteilung über Google Sheets.
Einrichtung des Apps Scripts: in der App unter Kosten → „⚙️ Einrichtung“.
