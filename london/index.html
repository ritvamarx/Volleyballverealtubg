⚙️ Einrichtung (Google Drive)

Lesen: Die App liest die Tabelle „London 2026 – Kosten“. Dafür muss sie entweder über Teilen → „Jeder mit dem Link“ → Betrachter freigegeben sein, oder das Apps Script unten muss eingerichtet sein.

Direkt in der App eintragen und Programm für alle ändern (einmalig, ca. 2 Minuten, macht die Besitzerin der Tabelle). Das Script speichert Ausgaben, Änderungen am Programm und freigegebene Standorte (legt dafür die Tabs „Programm“, „Standorte“ und „Fotos“ sowie den Drive-Ordner „London 2026 – Erinnerungen“ an). Ohne Script bleiben Programm-Änderungen nur auf dem eigenen Gerät, und Standorte können nicht geteilt werden. Wurde das Script schon früher bereitgestellt: Code ersetzen und unter Bereitstellen → Bereitstellungen verwalten → ✏️ → Version „Neue Version“ aktualisieren.

  1. Tabelle öffnen → Menü Erweiterungen → Apps Script
  2. Den vorhandenen Code löschen und den Code unten einfügen → 💾 speichern
  3. Bereitstellen → Neue Bereitstellung → Zahnrad ⚙️ → Typ Web-App
  4. Ausführen als: Ich · Zugriff: Jeder → Bereitstellen → Zugriff autorisieren
  5. Die Web-App-URL (endet auf /exec) kopieren und hier einfügen. Oder, damit alle sie automatisch haben: oben in dieser HTML-Datei bei SCRIPT_URL eintragen und die Datei neu verschicken.
